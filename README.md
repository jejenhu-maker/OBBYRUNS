# OBBYRUNS

A kid-friendly browser game prototype: race other Obby runners across floating 3D courses, collect coins, bounce on red trampolines, zoom on green speed pads, jump ramps, dodge spinning tires, and stay out of the water.

## Play

Open `index.html` in a browser, or deploy with GitHub Pages.

## Controls

- Keyboard: `←` / `→` or `A` / `D` to steer, `Space` to jump
- Phone / tablet: left joystick + right Jump button

## Tech

- Single-file HTML5 Canvas game
- No dependencies
- No build step
